# REMCO prototype

Prototipo visual creado por OSWIP Technologies para REMCO Renta Car.

- `index.html`: sitio comercial + flujo de reserva + arquitectura visual.
- `app.html`: propuesta de aplicación móvil.
- `admin.html`: vista conceptual del panel operativo conectado a Odoo.

Este prototipo es demostrativo. Los datos, precios, vehículos e indicadores son ilustrativos.
